OSM 3D buildings is the default and only needs a free Cesium token. Google Photorealistic is optional, loads on demand, and needs your own paid Google Cloud key. Keys stay in your browser and are never sent to this site's server.

Cesium ion token free · no card
How to get a free Cesium ion token (about 2 minutes)
  1. Open ion.cesium.com/signup and create a free account (email + password, or "Sign up with Google / GitHub"). No payment details are asked for.
  2. After you sign in, click Access Tokens in the top navigation bar (direct link: ion.cesium.com/tokens).
  3. A Default Token already exists. Click its row, then click the Copy button next to the long token string.
    (Or click Create token, type any name, leave the ticked scopes assets:read and geocode as they are, and Create, then copy it.)
  4. Paste it in the field above and click Use OSM 3D buildings.

The free tier is fine for personal use. The same token also turns on the address search box and the satellite base map.

Google Maps API key needs a card
How to get a Google Maps API key (credit card needed)
  1. Open the Google Cloud Console and sign in with a Google account.
  2. Create a project: top bar → project dropdown → New Project → give it a name → Create.
  3. Add billing: menu (☰) → Billing → Link a billing account → add a card. Google gives a recurring free monthly allowance, but a card is still required.
  4. Enable the API: menu → APIs & Services → Library, search Map Tiles API, open it, click Enable.
  5. Make the key: menu → APIs & Services → Credentials → Create credentials → API key. Copy the key it shows.
  6. Lock the key down (click Edit API key): Application restrictions → Websites → add http://localhost:3003/* and your site's address; API restrictions → Restrict key → tick Map Tiles API → Save.
  7. Paste it in the field above and click Load Google Photorealistic.

Your key is used from your browser only; this site never stores it. Still add the website + API restrictions above so it can't be misused elsewhere.

Not available in Europe: Google does not serve Photorealistic 3D Tiles to Google Cloud accounts based in the EU/EEA (you get "3D tiles are not available for your account and region"). OSM 3D buildings work everywhere. Google's notice.
